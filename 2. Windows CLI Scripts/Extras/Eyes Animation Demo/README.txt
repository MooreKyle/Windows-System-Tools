==========================================================================================
#                                   Eyes Animation Demo                                  #
==========================================================================================

This is a Halloween-themed console animation experiment,
created as an extra for Windows System Tools (WST).

To run this:
	- Double-click "Eyes Animation Demo.bat".
		- NOTE: Keep "Eyes Animation Engine.ps1" in the same folder.
	- Wait five seconds for the script to start, or press any key to begin instantly.
	- Press Ctrl+C ('Ctrl' and 'C' keys) to stop the animation at any time.

Features:
	- 20 independently blinking eyes.
	- Randomized blinking patterns 
	- Occasional changes in focus
	- Randomized visual effects.
Requirements:
	- Windows with Windows PowerShell 5.1 and the standard Windows console.
	- No third-party software required.

The program makes no network requests or persistent system changes.

Note:
	- This README is intentionally formatted for viewing alongside other windows
	  using Windows Snap Assist, should that be useful for your needs.
