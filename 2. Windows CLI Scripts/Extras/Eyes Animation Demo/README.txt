=======================
# Eyes Animation Demo #
=======================

This is a Halloween-themed console animation experiment for Windows System Tools (WST).

To run this:
	- Double-click "Eyes Animation Demo.bat" (Keep "Eyes Animation Engine.ps1" in the same folder).
	- The launcher will prompt you to either wait five seconds before starting, or you may press any key to begin immediately.
	- Like any batch script, press Ctrl+C ('Ctrl' and 'C' keys) to stop the animation at any time.

Features:
	- 20 independently blinking eyes
		- occasional changes in focus
		- randomized visual effects.
Requirements
	- Windows with Windows PowerShell 5.1 and the standard Windows console. No third-party software required.

The program makes no network requests or persistent system changes.
